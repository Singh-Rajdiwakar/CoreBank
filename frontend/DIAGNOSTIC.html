Troubleshooting Steps

# Step 1: Verify Backend is Running
Check if http://localhost:8080/swagger-ui/index.html loads

# Step 2: Clear Browser Cache
Press Ctrl+Shift+Delete, select "All time", clear cache

# Step 3: Force Reload
Press Ctrl+Shift+R (hard refresh) in browser

# Step 4: Check Dev Server
Terminal should show: "VITE v5.4.21 ready in XXX ms"
and "Local: http://localhost:3002/"

If Still Seeing White Screen:

⚠️ Likely Causes:
  • JavaScript error preventing React from rendering (check F12 console)
  • AuthContext or NotificationProvider initialization error
  • Router not set up correctly (but code looks fine)
  • CSS not loading (check if Tailwind works)
