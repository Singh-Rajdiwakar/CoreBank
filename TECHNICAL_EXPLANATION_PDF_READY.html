🔑 Foreign Keys & Relationships

Foreign Keys ek table ke data ko dusre table se connect karte hain. For example: 

accounts table:
├── account_id = 101
├── customer_id = 5 (← This is Foreign Key)
└── balance = 50000

users table:
├── user_id = 5
├── email = raj@bank.com
└── name = Raj Singh

🔄 Transfer Process - Detailed Flow:

STEP 1: Raj ne "Send Money" button daba

FRONTEND:
  ├─> onClick handler trigger
  ├─> Modal open hota hai
  └─> Transfer form dikhai deta hai

STEP 2: Raj form fill karte hain aur submit karte hain

Form data:
  ├─> Source Account: 1234567890123
  ├─> Recipient: Ravi Sharma
  ├─> Amount: ₹5,000
  └─> Submit!

STEP 3: Frontend validation

Check:
  ├─> Amount > 0? ✓ Yes
  ├─> Amount is number? ✓ Yes
  ├─> Recipient valid? ✓ Yes
  └─> All pass! API call bhej do

STEP 4: Backend receives aur processing start

TransactionController:
  ├─> POST /api/transactions/transfer
  ├─> Token verify: Raj Singh authentic? ✓ Yes
  └─> transactionService.transfer() call

TransactionService:
  ├─> Check: Source account exist? ✓ Yes
  ├─> Check: Destination account exist? ✓ Yes
  ├─> Check: Balance sufficient? ✓ Yes (50000 >= 5000)
  ├─> Check: Both accounts ACTIVE? ✓ Yes
  └─> Fraud analysis start

STEP 5: Fraud Detection Analysis

fraudDetectionService:
  
  Check 1 - AMOUNT ANOMALY:
    ├─> Raj ke previous transfers: 10K, 8K, 12K, 9K (avg: 9.75K)
    ├─> Current: 5K
    └─> Result: NORMAL ✓ (less than average)
  
  Check 2 - VELOCITY:
    ├─> Last 1 hour transactions: 0
    ├─> Threshold: 10
    └─> Result: NORMAL ✓
  
  Check 3 - GEOGRAPHIC:
    ├─> IP at login: Same as current
    └─> Result: NORMAL ✓
  
  Final: NOT FRAUDULENT ✓

STEP 6: Database Transaction Start (ATOMIC)

@Transactional // Matlab: Donon ho ya donon na ho

Query 1 - Deduct from source:
  UPDATE accounts 
  SET balance = balance - 5000 
  WHERE account_id = 101
  -- Result: 50000 → 45000

Query 2 - Add to recipient:
  UPDATE accounts 
  SET balance = balance + 5000 
  WHERE account_id = 102
  -- Result: 100000 → 105000

Query 3 - Record transaction:
  INSERT INTO transactions (from_acc, to_acc, amount, status)
  VALUES (101, 102, 5000, 'SUCCESS')

Query 4 - Audit log:
  INSERT INTO audit_logs (action, user_id, details)
  VALUES ('TRANSFER', 5, '...')
